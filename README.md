# Joe Al Sokhen - Portfolio

This is my personal software development portfolio. I use it to share my projects, internship experience, technical skills, and CV.

The site is plain HTML, CSS, and JavaScript, so there is no build step or package installation. The main files are:

- `index.html` for the content
- `assets/css/styles.css` for the design
- `assets/js/main.js` for navigation behavior
- `assets/Joe_Al_Sokhen_CV.pdf` for the public CV

To preview it locally, serve the repository folder with a basic web server and open the local address in a browser.

The site is published through GitHub Pages from the `main` branch. My real `.env` file and original CV documents are kept private and are not committed.

The public CV uses the one-page v3 Software Engineer / Full-Stack version, with military experience and the phone number omitted. The email address remains public. Its editable portfolio copy is `cv/Joe_Al_Sokhen_CV_Portfolio.docx`, inside the ignored `cv/` folder; the main v3 CV collection is unchanged. The portfolio also links to `l2ita.com` as “Additional apps.”
