01 Graduation project

ForenSight

AI-powered bloodstain pattern analysis

A portable forensic decision-support application that classifies bloodstain images locally, without uploading evidence to a remote service.

  • Flutter
  • Dart
  • TensorFlow Lite
  • Vertex AI
  • Python
96.65%precision on unseen test data
0.933Macro F1 score
7supported subclasses
Technical approach
Bundled versioned TFLite models, runtime tensor inspection, device-local preprocessing, and per-class confidence thresholds.
Engineering challenge
Balancing fast offline inference with conservative handling of uncertain results. Low-confidence output is flagged for review rather than forced into a class.
Collaboration
Developed the graduation project in close collaboration with the forensics department.
Result
Sub-second inference on device with top predictions, confidence context, and no image upload dependency.

Decision-support and educational use only; not a substitute for qualified forensic analysis.
